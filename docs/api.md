# Brunernetes API reference - `bruner.dev/v1alpha1`

This document is the API proposal and reference for the four custom resources
Brunernetes defines. It is generated by hand from the Go types in
`api/v1alpha1` and is authoritative together with them. Where this document and
the code disagree, the code wins; report the discrepancy as a bug.

- Group: `bruner.dev`
- Version: `v1alpha1`
- Stability: alpha. Fields may change without a conversion webhook until
  `v1beta1`.
- Kinds: [`Togliatti`](#togliatti), [`AvtoVAZ`](#avtovaz),
  [`BrunerApp`](#brunerapp), [`Konveer`](#konveer)

Design rationale for the scopes and for the absence of an admission webhook is
in [ADR 0002](adr/0002-crd-and-controller-boundary.md). Controller behaviour is
in [reconciliation.md](reconciliation.md).

## Conventions used in this document

- **Default** is the value applied by the API server from a
  `+kubebuilder:default` marker. Values applied by the controller at runtime
  are listed as *controller default* and are visible in status, not in spec.
- **Validation** lists the constraints enforced by the CRD OpenAPI schema, that
  is, by the API server at admission time.
- Every optional field carries `omitempty`. A pointer type (`*bool`, `*int32`,
  `*BrunerMode`) means "unset" is distinguishable from the zero value.
- All conditions follow the standard `metav1.Condition` contract:
  `type`, `status`, `observedGeneration`, `lastTransitionTime`, `reason`,
  `message`. All condition lists are `listType=map` keyed on `type` with
  `patchStrategy=merge`.
- Every `message` states the technical condition first and the themed wording
  second.

## Shared types

### `BrunerMode`

The operating mode of the factory or of a single application. Every field is
optional so that an application inherits unset fields from the cluster-scoped
`AvtoVAZ` policy.

| Field | Type | Default | Validation | Description |
| --- | --- | --- | --- | --- |
| `profile` | `Profile` (string) | none (see merge rules) | Enum: `garage`, `showroom`, `strict`, `friday` | Operating profile |
| `rollout` | `Rollout` (string) | none | Enum: `steady` | Rollout strategy. Only `steady` exists |
| `qualityGate` | `QualityGate` (string) | none | Enum: `practical`, `strict` | How strictly quality checks are enforced |
| `shift` | `Shift` (string) | none | Enum: `day`, `night` | Working shift |

**Profiles**

| Profile | Meaning |
| --- | --- |
| `garage` | Minimal local developer configuration |
| `showroom` | Presentation-friendly configuration; `minReadySeconds` is raised to 5 so a demonstration does not flicker between states |
| `strict` | Requires a readiness probe and CPU and memory requests |
| `friday` | Requires an explicit `override` for a guarded change such as an image change |

**Quality gates**

| Gate | Meaning |
| --- | --- |
| `practical` | Policy problems are reported as warnings; the rollout continues |
| `strict` | Policy problems block the rollout |

**Shifts**

| Shift | Meaning |
| --- | --- |
| `day` | Default. Periodic resync every 30 s |
| `night` | Reduced reporting noise; periodic resync every 2 min |

**Merge rules** (`MergeModes` in `api/v1alpha1/validation.go`). Modes are layered
from lowest to highest precedence - factory default, then application override -
and every field still empty falls back to `DefaultMode()`:

```
profile: garage   rollout: steady   qualityGate: practical   shift: day
```

The merged result is reported in `status.effectiveMode` on both `AvtoVAZ` and
`BrunerApp`. It is never written back into the spec.

`BrunerMode` also carries three helpers used by the controllers:
`RequiresReadinessProbe()` and `RequiresResourceRequests()` are true when the
profile is `strict` or the quality gate is `strict`; `RequiresOverride()` is
true when the profile is `friday`.

### `LocalExposure`

Localhost-only exposure. See [ADR 0003](adr/0003-localhost-only-exposure.md).

| Field | Type | Default | Validation | Description |
| --- | --- | --- | --- | --- |
| `enabled` | `*bool` | `true` | - | Request a loopback host port binding in addition to the always-created ClusterIP Service |
| `hostIP` | `string` | `"127.0.0.1"` | Pattern `^127\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}$` | The loopback address to bind |
| `hostPort` | `int32` | `30080` | Minimum 1024, Maximum 65535 | The loopback port to publish on |

The pattern is a schema-level guard. `IsLoopbackHostIP` re-checks the `127.`
prefix in the controller, and a non-loopback value is replaced with
`127.0.0.1` rather than honoured.

### `AppOverride`

An explicit human acknowledgement of a guarded change.

| Field | Type | Default | Validation | Description |
| --- | --- | --- | --- | --- |
| `approved` | `bool` | `false` | required | Enables the guarded change |
| `image` | `string` | `""` | - | The exact image reference the approval applies to. The approval is ignored when it does not match `spec.image` |
| `reason` | `string` | `""` | MaxLength 256 | Why the change was approved |

An override with an empty `image` approves any image. An override with a
non-matching `image` approves nothing.

### `LatestTagPolicy`

Enum: `Ignore`, `Warn`, `Reject`.

| Value | Behaviour on a mutable reference |
| --- | --- |
| `Ignore` | Accepted silently |
| `Warn` | Accepted; `PolicyWarning=True` with reason `PolicyDeviation` and a `Warning` event |
| `Reject` | Rollout blocked; `Degraded=True` with reason `PolicyViolation` |

"Mutable" is decided by `ImageReference.IsMutable()`: a reference is mutable
when it carries no digest **and** the tag is empty or `latest`. A digest-pinned
reference is never mutable.

### `AssemblyStage`

Enum: `Inspection`, `Assembly`, `QualityControl`, `Showroom`, `LineStopped`.
Themed progress reporting only; it mirrors the technical conditions and is
never the source of truth.

| Stage | Technical meaning |
| --- | --- |
| `Inspection` | The desired state is being validated, or a policy violation is holding the rollout |
| `Assembly` | Replicas are being created or updated |
| `QualityControl` | Replicas exist but not all of them are ready |
| `Showroom` | Every desired replica is ready and updated |
| `LineStopped` | A fault blocks progress: unschedulable, image pull failure, crash loop, progress deadline exceeded, or a reconcile error |

### Condition types and reasons

All type and reason constants live in `api/v1alpha1/common_types.go`.

| Condition type | Used by | Meaning |
| --- | --- | --- |
| `Reconciling` | `BrunerApp` | The controller is converging the resource |
| `Available` | `Togliatti`, `BrunerApp` | The resource serves its purpose |
| `Degraded` | `BrunerApp`, `Konveer` | A technical fault blocks progress |
| `PolicyWarning` | `BrunerApp` | A non-blocking policy deviation |
| `APIHealthy` | `Togliatti` | Kubernetes API server health |
| `NodeReady` | `Togliatti` | Node readiness |
| `RuntimeAvailable` | `Togliatti` | Container runtime availability |
| `CNIHealthy` | `Togliatti` | Pod network health |
| `LocalEndpointCapable` | `Togliatti` | The node can publish a loopback endpoint |
| `PolicyEnforced` | `AvtoVAZ` | Factory policy is in effect |
| `CapacityRespected` | `AvtoVAZ` | The application count is within the maximum |
| `Validated` | `Konveer` | The delivery passed validation |
| `RolledOut` | `Konveer` | The delivery finished its rollout |
| `Verified` | `Konveer` | The localhost endpoint was verified |
| `Succeeded` | `Konveer` | Terminal success of the delivery |

| Reason | Typical condition | Meaning |
| --- | --- | --- |
| `Reconciling` | `Reconciling=True`, `Degraded=False` | Work is in progress and no fault was detected |
| `ReconcileError` | `Degraded=True` | The controller could not read or write an object |
| `AllReplicasReady` | `Available=True` | Every desired replica is ready and updated |
| `ReplicasUnavailable` | `Available=False` | Replica count is zero by request, or pods cannot be scheduled |
| `ImagePullFailure` | `Degraded=True` | `ErrImagePull`, `ImagePullBackOff`, `InvalidImageName` or `ImageInspectError` |
| `ProbeFailure` | `Available=False` | Readiness is not succeeding, or the container is in a crash loop |
| `PolicyViolation` | `Degraded=True` | A blocking policy check failed |
| `PolicyDeviation` | `PolicyWarning=True` | A non-blocking policy check failed |
| `OverrideRequired` | `Degraded=True` | The `friday` profile is holding an image change |
| `CapacityExceeded` | `CapacityRespected=False` | More `BrunerApp` resources exist than `maxApplications` allows |
| `ValidationFailed` | `Validated=False` | The image reference or the operating mode is invalid |
| `ValidationPassed` | `Validated=True`, `PolicyWarning=False` | Validation succeeded with no findings |
| `RolloutTimeout` | `RolledOut=False`, `Degraded=True` | The Deployment exceeded its progress deadline or the configured rollout timeout |
| `EndpointUnverified` | `Verified=False` | The endpoint did not answer as expected |
| `EndpointVerified` | `Verified=True` | The endpoint answered the expected status |
| `ProbeSucceeded` | `APIHealthy`, `NodeReady`, `RuntimeAvailable`, `CNIHealthy` | An environment probe succeeded |
| `ProbeFailed` | same | An environment probe failed |

## Togliatti

**Purpose.** Describes the single-node factory environment: the Kubernetes API,
the node, the container runtime, the pod network, and the resources available to
build products on. It is a pure observer - it owns nothing and writes only its
own status.

**Scope.** Cluster. Conventionally one instance named `togliatti`.

**Resource metadata.** Plural `togliattis`; short names `tgl`, `factory`;
category `brunernetes`; status subresource enabled.

### `spec`

| Field | Type | Default | Validation | Description |
| --- | --- | --- | --- | --- |
| `nodeName` | `string` | `""` | - | The node hosting the factory. When empty the controller uses the only node in the cluster |
| `capacityProfile` | `CapacityProfile` (string) | `""` | Enum: `compact`, `standard`, `spacious` | Requests a capacity profile. When empty the controller derives it from the observed node capacity |
| `probeIntervalSeconds` | `int32` | `60` | Minimum 10, Maximum 3600 | How often the environment is re-checked |
| `expectedKubernetesVersion` | `string` | `""` | Pattern `^v[0-9]+\.[0-9]+\.[0-9]+$` | The pinned control-plane version the installer produced. A mismatch is reported but does not stop the line |
| `expectedRuntime` | `string` | `"containerd"` | Enum: `containerd` | The container runtime the installer configured |

Capacity profiles: `compact` suits a 2 vCPU / 4 GB host, `standard` a
4 vCPU / 8 GB host, `spacious` anything larger.

### `status`

| Field | Type | Description |
| --- | --- | --- |
| `observedGeneration` | `int64` | The spec generation this status refers to |
| `nodeName` | `string` | The observed node |
| `kubernetesVersion` | `string` | The kubelet version reported by the node |
| `containerRuntime` | `string` | The runtime reported by the node, for example `containerd://1.7.24` |
| `activeCapacityProfile` | `CapacityProfile` | The capacity profile in use |
| `resources` | `*NodeResources` | Node capacity and allocatable resources |
| `schedulableForWorkloads` | `bool` | Whether ordinary workloads may run on the control-plane node, which a single-node factory requires |
| `localEndpointCapable` | `bool` | Whether loopback host port publishing is available on this node |
| `lastProbeTime` | `*metav1.Time` | When the environment was last checked |
| `conditions` | `[]metav1.Condition` | `APIHealthy`, `NodeReady`, `RuntimeAvailable`, `CNIHealthy`, `LocalEndpointCapable`, `Available` |

`NodeResources`:

| Field | Type | Description |
| --- | --- | --- |
| `cpuCapacity` | `string` | Total CPU capacity, for example `"2"` |
| `cpuAllocatable` | `string` | Allocatable CPU |
| `memoryCapacity` | `string` | Total memory, for example `"4Gi"` |
| `memoryAllocatable` | `string` | Allocatable memory |
| `ephemeralStorageAllocatable` | `string` | Allocatable ephemeral storage |
| `pods` | `int64` | Maximum number of pods the node accepts |

### Printer columns

| Name | Type | JSONPath |
| --- | --- | --- |
| Node | string | `.status.nodeName` |
| Kubernetes | string | `.status.kubernetesVersion` |
| Capacity | string | `.status.activeCapacityProfile` |
| Node ready | string | `.status.conditions[?(@.type=="NodeReady")].status` |
| Available | string | `.status.conditions[?(@.type=="Available")].status` |
| Age | date | `.metadata.creationTimestamp` |

### Example

```yaml
apiVersion: bruner.dev/v1alpha1
kind: Togliatti
metadata:
  name: togliatti
spec:
  nodeName: brunernetes-node
  capacityProfile: compact
  probeIntervalSeconds: 60
  expectedKubernetesVersion: v1.32.3
  expectedRuntime: containerd
```

## AvtoVAZ

**Purpose.** Factory-wide configuration and policy: the default operating mode
every application inherits, and the safety and quality rules every application
is measured against. It owns nothing and writes only its own status.

**Scope.** Cluster. Conventionally one instance named `avtovaz`. When several
exist, the `BrunerApp` controller selects the one named `avtovaz`, falling back
to the alphabetically first. When none exists, the built-in defaults from
`factory.DefaultPolicy()` apply, so a fresh cluster works without any
`AvtoVAZ` resource.

**Resource metadata.** Plural `avtovazs`; short name `vaz`; category
`brunernetes`; status subresource enabled.

### `spec`

| Field | Type | Default | Validation | Description |
| --- | --- | --- | --- | --- |
| `defaultMode` | `*BrunerMode` | `nil` | see [`BrunerMode`](#brunermode) | The mode inherited by every application that does not set its own mode fields |
| `policy` | `*FactoryPolicy` | `nil` | see below | The factory safety and quality policy |
| `factoryRef` | `string` | `"togliatti"` | - | The name of the `Togliatti` resource this policy applies to |

### `spec.policy` - `FactoryPolicy`

| Field | Type | Default | Validation | Description |
| --- | --- | --- | --- | --- |
| `requireReadinessProbe` | `*bool` | `false` | - | Rejects or warns about applications without a readiness probe, depending on the active quality gate |
| `requireResourceRequests` | `*bool` | `false` | - | Rejects or warns about applications without CPU and memory requests, depending on the active quality gate |
| `latestTagPolicy` | `LatestTagPolicy` | `Warn` | Enum: `Ignore`, `Warn`, `Reject` | How a mutable tag is handled |
| `maxApplications` | `int32` | `1` | Minimum 1, Maximum 1 | The maximum number of `BrunerApp` resources allowed in the cluster. The MVP supports exactly one |
| `allowedRegistries` | `[]string` | `[]` | - | Restricts image references to the listed registry prefixes. An empty list allows any registry |
| `allowPublicExposure` | `*bool` | `false` | Enum: `false` | Always false in the MVP. The field exists to make the localhost-only guarantee explicit and auditable |

`maxApplications` is schema-pinned to exactly 1 in `v1alpha1`. Both the minimum
and the maximum are 1, so the field cannot express any other value; it exists so
that the constraint is visible in the API rather than hidden in code.

`allowedRegistries` matching (`RegistryAllowed`) accepts an entry when it equals
the parsed registry host, or when `<registry>/<repository>` starts with the
entry plus a slash. Entries are trimmed; empty entries are ignored.

Whether the readiness-probe and resource-request requirements *block* or only
*warn* depends on the effective quality gate: with `qualityGate: strict` or
`profile: strict` they are violations, otherwise they are warnings.

### `status`

| Field | Type | Description |
| --- | --- | --- |
| `observedGeneration` | `int64` | The spec generation this status refers to |
| `effectiveMode` | `*BrunerMode` | The fully defaulted factory mode |
| `applicationCount` | `int32` | The number of `BrunerApp` resources observed |
| `maxApplications` | `int32` | The enforced application limit |
| `conditions` | `[]metav1.Condition` | `PolicyEnforced`, `CapacityRespected` |

### Printer columns

| Name | Type | JSONPath |
| --- | --- | --- |
| Profile | string | `.status.effectiveMode.profile` |
| Quality gate | string | `.status.effectiveMode.qualityGate` |
| Apps | string | `.status.applicationCount` |
| Max apps | string | `.status.maxApplications` |
| Age | date | `.metadata.creationTimestamp` |

### Example

```yaml
apiVersion: bruner.dev/v1alpha1
kind: AvtoVAZ
metadata:
  name: avtovaz
spec:
  factoryRef: togliatti
  defaultMode:
    profile: showroom
    rollout: steady
    qualityGate: practical
    shift: day
  policy:
    requireReadinessProbe: true
    requireResourceRequests: false
    latestTagPolicy: Warn
    maxApplications: 1
    allowedRegistries:
      - ghcr.io
      - registry.k8s.io
    allowPublicExposure: false
```

## BrunerApp

**Purpose.** The single web application assembled and published by the factory.
The controller creates and owns one `Deployment` and one `Service`, applies
factory defaults for resources and probes, sets labels and owner references, and
publishes the application on the loopback interface.

**Scope.** Namespaced.

**Owned objects.** One `apps/v1 Deployment` and one `v1 Service`, both named
after the `BrunerApp` and both carrying a controller owner reference back to it.
Deleting the `BrunerApp` removes both by garbage collection.

**Resource metadata.** Plural `brunerapps`; short names `bapp`, `app`; category
`brunernetes`; status subresource enabled.

### `spec`

| Field | Type | Default | Validation | Description |
| --- | --- | --- | --- | --- |
| `image` | `string` | - (required) | MinLength 1, MaxLength 512 | Container image reference of an already-built image. Brunernetes never builds images |
| `imagePullPolicy` | `corev1.PullPolicy` | `""` | Enum: `Always`, `IfNotPresent`, `Never` | Overrides the container image pull policy |
| `imagePullSecrets` | `[]corev1.LocalObjectReference` | `[]` | - | Registry credentials in the same namespace |
| `replicas` | `*int32` | `1` | Minimum 0, Maximum 5 | Desired replica count. A single node runs few replicas, so the maximum is deliberately low |
| `port` | `int32` | `8080` | Minimum 1, Maximum 65535 | The container port serving HTTP traffic |
| `healthPath` | `string` | `"/healthz"` | Pattern `^/.*$` | The HTTP path used for the default probes |
| `mode` | `*BrunerMode` | `nil` | see [`BrunerMode`](#brunermode) | Overrides the factory default operating mode for this application |
| `localExposure` | `*LocalExposure` | `nil` (behaves as enabled on `127.0.0.1:30080`) | see [`LocalExposure`](#localexposure) | Loopback-only host port binding |
| `env` | `[]corev1.EnvVar` | `[]` | - | Additional environment variables for the container |
| `resources` | `*corev1.ResourceRequirements` | `nil` | - | Overrides the default requests and limits. Fields left empty are filled with factory defaults |
| `readinessProbe` | `*corev1.Probe` | `nil` | - | Overrides the default readiness probe |
| `livenessProbe` | `*corev1.Probe` | `nil` | - | Overrides the default liveness probe |
| `serviceAccountName` | `string` | `""` | - | The service account used by the application pods |
| `override` | `*AppOverride` | `nil` | see [`AppOverride`](#appoverride) | Acknowledges a change the active profile would otherwise hold back |

**Controller defaults applied to the owned objects** (from `internal/factory`,
not written back into the spec):

| Concern | Applied value |
| --- | --- |
| Resource requests | `cpu: 50m`, `memory: 64Mi` - only for keys the spec leaves unset |
| Resource limits | `cpu: 500m`, `memory: 256Mi` - only for keys the spec leaves unset |
| Readiness probe | `HTTPGet` on `healthPath`:`port`, `initialDelaySeconds: 2`, `periodSeconds: 5`, `timeoutSeconds: 2`, `successThreshold: 1`, `failureThreshold: 3` |
| Liveness probe | `HTTPGet` on `healthPath`:`port`, `initialDelaySeconds: 10`, `periodSeconds: 20`, `timeoutSeconds: 3`, `successThreshold: 1`, `failureThreshold: 5` |
| Rollout strategy | `RollingUpdate` with `maxSurge: 0`, `maxUnavailable: 1` - the `steady` strategy |
| `minReadySeconds` | `5` under the `showroom` profile, otherwise `0` |
| `revisionHistoryLimit` | `3` |
| `progressDeadlineSeconds` | `300` |
| Container name | `application` |
| Container security context | `allowPrivilegeEscalation: false`, `privileged: false`, `capabilities.drop: ["ALL"]`, `seccompProfile: RuntimeDefault` |
| Service | `ClusterIP`, port `80` named `http`, targeting the named container port `http` |
| Selector labels (immutable) | `app.kubernetes.io/name`, `app.kubernetes.io/instance` = the `BrunerApp` name; `app.kubernetes.io/part-of: brunernetes-factory` |
| Additional labels | `app.kubernetes.io/managed-by: brunernetes`, `app.kubernetes.io/component: application`, `bruner.dev/profile`, `bruner.dev/shift` |
| Annotations | `bruner.dev/applied-image`, `bruner.dev/quality-gate`, `bruner.dev/local-endpoint` |

The container security context does **not** force `runAsNonRoot`, because the
image is supplied by the user and may legitimately define its own user.

### `status`

| Field | Type | Description |
| --- | --- | --- |
| `observedGeneration` | `int64` | The spec generation this status refers to |
| `stage` | `AssemblyStage` | Themed progress stage derived from the technical status |
| `replicas` | `int32` | Replicas currently created |
| `readyReplicas` | `int32` | Replicas that passed readiness |
| `deploymentName` | `string` | The owned Deployment |
| `serviceName` | `string` | The owned Service |
| `clusterIPEndpoint` | `string` | In-cluster endpoint, `http://<service>.<namespace>.svc.cluster.local:80` |
| `localEndpoint` | `string` | Loopback endpoint, `http://<hostIP>:<hostPort>`, empty when local exposure is disabled |
| `appliedImage` | `string` | The image currently rolled out |
| `effectiveMode` | `*BrunerMode` | The mode after merging the `AvtoVAZ` defaults with the application override |
| `conditions` | `[]metav1.Condition` | `Reconciling`, `Available`, `Degraded`, `PolicyWarning` |

### Printer columns

| Name | Type | JSONPath |
| --- | --- | --- |
| Stage | string | `.status.stage` |
| Ready | string | `.status.readyReplicas` |
| Replicas | string | `.status.replicas` |
| Local endpoint | string | `.status.localEndpoint` |
| Available | string | `.status.conditions[?(@.type=="Available")].status` |
| Age | date | `.metadata.creationTimestamp` |

### Example

```yaml
apiVersion: bruner.dev/v1alpha1
kind: BrunerApp
metadata:
  name: factory-showroom
  namespace: brunernetes-demo
spec:
  image: ghcr.io/brunka09/factory-showroom:v0.1.0
  imagePullPolicy: IfNotPresent
  replicas: 1
  port: 8080
  healthPath: /healthz
  serviceAccountName: default
  mode:
    profile: showroom
    rollout: steady
    qualityGate: practical
    shift: day
  localExposure:
    enabled: true
    hostIP: 127.0.0.1
    hostPort: 30080
  env:
    - name: SHOWROOM_TITLE
      value: Factory Showroom
  resources:
    requests:
      cpu: 50m
      memory: 64Mi
    limits:
      cpu: 500m
      memory: 256Mi
  readinessProbe:
    httpGet:
      path: /healthz
      port: 8080
    initialDelaySeconds: 2
    periodSeconds: 5
    timeoutSeconds: 2
    successThreshold: 1
    failureThreshold: 3
  livenessProbe:
    httpGet:
      path: /healthz
      port: 8080
    initialDelaySeconds: 10
    periodSeconds: 20
    timeoutSeconds: 3
    successThreshold: 1
    failureThreshold: 5
  override:
    approved: true
    image: ghcr.io/brunka09/factory-showroom:v0.1.0
    reason: Reviewed and approved by the platform team.
```

## Konveer

**Purpose.** A lightweight delivery workflow for an image that already exists in
a registry. It validates the image reference and the factory policy, applies the
referenced `BrunerApp`, waits for the rollout and readiness, and verifies the
loopback endpoint where that is possible. It never builds images - see
[ADR 0004](adr/0004-delivery-without-image-build.md).

**Scope.** Namespaced. `spec.appRef` names a `BrunerApp` in the **same**
namespace.

**Ownership.** `Konveer` does **not** own the `BrunerApp` it delivers to. It
creates the `BrunerApp` when it does not exist and updates it otherwise, but
deleting a finished `Konveer` never deletes the running application.

**Resource metadata.** Plural `konveers`; short names `kvr`, `line`; category
`brunernetes`; status subresource enabled.

### `spec`

| Field | Type | Default | Validation | Description |
| --- | --- | --- | --- | --- |
| `appRef` | `string` | - (required) | MinLength 1, MaxLength 253 | The `BrunerApp` in the same namespace this workflow delivers to. Created when it does not exist |
| `image` | `string` | - (required) | MinLength 1, MaxLength 512 | The already-built image reference to deliver |
| `appTemplate` | `*KonveerAppTemplate` | `nil` | see below | Optional `BrunerApp` spec fields applied together with the image. Fields left empty keep the current value |
| `checks` | `*KonveerChecks` | `nil` | see below | Which policy checks run before the image is applied |
| `timeouts` | `*KonveerTimeouts` | `nil` | see below | Bounds on the rollout and readiness waits |
| `verify` | `*KonveerVerify` | `nil` | see below | The localhost endpoint check performed after readiness |
| `override` | `*AppOverride` | `nil` | see [`AppOverride`](#appoverride) | Acknowledges a guarded change, for example an image change under the `friday` profile |

#### `spec.appTemplate` - `KonveerAppTemplate`

| Field | Type | Default | Validation | Description |
| --- | --- | --- | --- | --- |
| `replicas` | `*int32` | `nil` | Minimum 0, Maximum 5 | Overrides the application replica count |
| `port` | `*int32` | `nil` | Minimum 1, Maximum 65535 | Overrides the container port |
| `healthPath` | `string` | `""` | Pattern `^/.*$` | Overrides the probe path |
| `mode` | `*BrunerMode` | `nil` | see [`BrunerMode`](#brunermode) | Overrides the application operating mode |
| `localExposure` | `*LocalExposure` | `nil` | see [`LocalExposure`](#localexposure) | Overrides the loopback exposure configuration |

#### `spec.checks` - `KonveerChecks`

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `imageReference` | `*bool` | `true` | Validate that the image reference is well formed |
| `policy` | `*bool` | `true` | Validate the delivery against the `AvtoVAZ` factory policy |
| `capacity` | `*bool` | `true` | Validate that the application limit is respected |

#### `spec.timeouts` - `KonveerTimeouts`

| Field | Type | Default | Validation | Description |

| `readinessSeconds` | `int32` | `180` | Minimum 10, Maximum 3600 | Bounds the readiness wait after the rollout completes |

#### `spec.verify` - `KonveerVerify`

| Field | Type | Default | Validation | Description |
| --- | --- | --- | --- | --- |
| `enabled` | `*bool` | `true` | - | Turns the endpoint check on. The check is skipped, not failed, when the controller cannot reach the node's loopback endpoint |
| `path` | `string` | `"/healthz"` | Pattern `^/.*$` | The HTTP path requested during verification |
| `expectedStatus` | `int32` | `200` | Minimum 100, Maximum 599 | The HTTP status code that counts as success |

## Image reference parsing

`ParseImageReference` in `api/v1alpha1/validation.go` is the single parser used
by every policy check. It never contacts a registry.

| Input | Registry | Repository | Tag | Digest | Mutable |
| --- | --- | --- | --- | --- | --- |
| `nginx` | `docker.io` | `library/nginx` | `latest` | - | yes |
| `nginx:1.27` | `docker.io` | `library/nginx` | `1.27` | - | no |
| `ghcr.io/brunka09/factory-showroom:v0.1.0` | `ghcr.io` | `brunka09/factory-showroom` | `v0.1.0` | - | no |
| `localhost:5000/showroom:dev` | `localhost:5000` | `showroom` | `dev` | - | no |
| `registry.k8s.io/pause@sha256:<64 hex>` | `registry.k8s.io` | `pause` | - | `sha256:<64 hex>` | no |

Rejected inputs: an empty reference, leading or trailing whitespace, any
embedded whitespace, an empty tag, an empty repository or repository segment,
and a digest that is not exactly `sha256:` followed by 64 characters.

The first path segment is treated as a registry host only when it equals
`localhost` or contains `.` or `:`. A bare Docker Hub name is expanded to
`library/<name>`. A reference with neither tag nor digest is given the tag
`latest`.
